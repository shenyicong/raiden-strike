## 📌 这是什么

一个**开箱即玩**的街机纵向射击游戏，致敬经典《雷电》系列：操纵战机穿越三区敌舰封锁线，击沉分段 Boss。

**没有任何构建工具、没有任何 npm 依赖、没有一张图片素材。** 所有机体、弹幕、粒子、星空、UI 由 Canvas 2D 路径实时绘制，音效由 WebAudio 振荡器实时合成。整个游戏就是一堆 `.js` 文件 —— 下载后用浏览器打开即可。

## 🕹 怎么玩（两种入口）

**方式 A · 单文件版（推荐，双击就玩）**
直接双击 `raiden-strike.html` 即可，无需服务器、无需联网。
> V2.0 新增：把 17 个 ES Module 内联成单个 classic `<script>`，**彻底修复 v1.0 在 `file://` 下因 ES Module CORS 直接白屏（"游戏打不开"）的问题**。

**方式 B · 模块化版（开发 / 部署用）**
```bash
git clone https://github.com/shenyicong/raiden-strike.git
cd raiden-strike
python -m http.server 8080      # 需要静态服务器（ES Module 限制）
# 浏览器打开 http://localhost:8080
```

## 🎮 操作

| 按键 | 功能 |
|---|---|
| `W A S D` / `方向键` | 移动战机 |
| 自动射击 | 无需按键，持续开火 |
| `K` / `X` | 炸弹：清空全屏弹幕并造成大量伤害（v2.2 恢复可用） |
| `Shift` | 精确移动（半速，弹幕里穿针用） |
| `P` / `Esc` | 暂停 |
| `M` | 静音开关 |
| `Enter` | 开始 / 继续 |

**鼠标 / 触屏**：直接拖动战机，拖动期间自动开火 —— 手机上也能玩。

**手机端专属**：打开链接会自动识别触屏设备，屏幕右下角出现【炸】按钮放炸弹，左下角【‖】暂停、【慢】精确移动（半速穿弹幕）；拖动采用"跟手偏移"，手指走多少机身走多少，不会跳变。

> 判定点只有机身中心那个**白色小点**（默认半径 9px，随机型 6–11px 变化），比视觉尺寸小很多，按判定点躲弹即可。

## ✨ 核心特性

### 战斗手感
- **五级火力进化**：吃 `P` 道具逐级升级，中弹掉一级。
- **擦弹爽感**：判定点小 + 精确移动模式，配合受击无敌闪烁。
- **炸弹清屏**：`B` 补给掉落并入库，`K`/`X`（手机点【炸】）引爆 —— 瞬间清空敌弹、全场 150 伤害、1.5s 无敌。
- **道具吸附**：靠近 130px 内的道具会被自动吸过来。

### 战机与解锁（v2.1）
标题界面可选择战机，共 6 架，随关卡进度解锁：

| 战机 | 特点 | 解锁条件 |
|---|---|---|
| 雷霆号 | 均衡型，速度/射速/伤害全基准，判定 9px | 初始 |
| 幻影 | 速度 +25%，判定仅 6px，生命 −1 | 初始 |
| 重装堡垒 | 生命 +2、伤害 +10%，判定 11px，移动偏慢 | 到达**第 2 区** |
| 猎鹰 | 射速 +25%，机动略强 | 到达**第 3 区** |
| 极光 | 伤害 +30% 贯通重炮 | **通关**战役 |
| 凤凰 | 受击不掉火力等级 | 单局 **20,000 分** |

解锁进度写入本地存档，重开游戏后保留。

### 关卡结构
- **三个区域**：近地轨道 → 陨石带 → 母舰外围，每区独立配色与波次脚本。
- **波次编队**：横排、V 字、弧线、俯冲四种阵型，逐区变强。
- **每关清理阈值（v2.6）**：每区设定需要清理的敌机数 —— 近地轨道 18 架 / 陨石带 24 架 / 母舰外围 30 架。
  达标即停止刷怪，场上清空后 Boss 立刻登场。HUD 右上角实时显示 `CLEAR 12/18`，达标后变成 `BOSS 待命`。
  阈值写在 `REGIONS[i].quota`；波次数量仍随对局时间成长（见下方 v2.4 动态难度）。
- **三段式 Boss**：血量降到 66% / 33% 触发阶段转换，**七种弹幕模式**（瞄准/环形/交叉/螺旋/扇形/弹墙/三连爆发）轮换。


### 难度与画风（v2.3）
- **画风回归第一版**：敌机恢复矢量描边造型（侦察机/战斗机/重甲六边形/自爆机/炮塔各自独立造型 + 发光核心 + 血条）；自机恢复渐变座舱、发光翼尖与推进器火焰；Boss 恢复分段装甲与能量环，配色随区域；子弹恢复外发光 + 亮核。
- **难度整体下调**：敌机血量 −12%、速度 −12%、开火频率 −25%；敌弹速度 180→150，Boss 弹速 160→132；Boss 阶段间隔放宽到 1.8/1.5/1.2 秒，血量 −5%；同波敌机数约 −20%；掉落率 0.14→0.20 且护盾占比提高；标准档初始生命 3→4、瞄准加入偏差、弹速 ×0.85。


### 循序渐进的动态难度（v2.4）
敌机的**血量、射速、弹速、每波数量**随本局存活时间连续平滑上升（不是一档一跳），120 秒后封顶不再变难：

| 存活时间 | 血量 | 射速 | 弹速 | 每波额外敌机 |
|---|---|---|---|---|
| 0 秒 | ×1.00 | ×1.00 | ×1.00 | +0 |
| 60 秒 | ×1.36 | ×1.36 | ×1.15 | +1 |
| 120 秒（封顶） | ×1.72 | ×1.72 | ×1.30 | +3 |

敌机血条会随血量增长变长；参数集中在 `config.js` 的 `RAMP`，改一个数即可调整曲线斜率。

### 道具随机爆率（v2.4）
- 掉落池加入**生命道具（♥）**，护盾与生命各有独立爆率：未命中基础掉落率时，仍会按 6% 生命 / 10% 护盾再掷一次
- 池内权重：火力 42% / 炸弹 18% / 护盾 22% / 生命 18%
- 拾取生命 +1 命（上限 9），拾取护盾 5 秒无敌

### 漏网敌机带伤重整（v2.5）
没打死、飘到我方战机下方的敌机不再无限堆积：越过屏幕下缘即离场，3 秒后**带着被你打剩的血量**从上方重返战场
（血条沿用原满血值，能直观看出"这架已经被打残了"）。每架最多重整 2 次，队列上限 6 架，参数见 `config.js` 的 `RALLY`。

### 背景音乐（v2.6.1）
用 WebAudio 实时合成的 BGM（**零音频文件**）：8 分音符步进音序器，含**贝斯 + 琶音 + 主旋律 + 底鼓/踩镲**四条轨。
三个区域各一套主题（近地轨道 132BPM 明亮推进 / 陨石带 140BPM 低沉压迫 / 母舰外围 148BPM 急促紧张），
**Boss 出场自动切到紧张版**（152 / 158 / 164 BPM）；暂停即停乐，结算自动收尾。
按 `M` 静音，音量受音乐总线控制。曲库在 `audio.js` 的 `MUSIC_TRACKS`。

### 难度再平衡（v2.6.1）
- **敌机射速 +50%**：战斗机 1.00→1.50、重甲 0.70→1.05、炮塔 1.15→1.73（数值见 `ENEMIES`）
- **敌机伤害 +50%**：引入"每条命的耐久"（`PLAYER.LIFE_HP = 100`），一发敌弹造成 150 点伤害 ——
  扣光当前这条命后溢出继续扣下一条，所以**两发掉三命**。HUD 生命下方新增装甲条显示当前命的剩余耐久。
  旧接口 `takeHit()` 不传参仍是"一击一命"，行为不变。
- **蓝条积攒变慢**：伤害 0.35→0.20、击破 4→2.2、擦弹 0.6→0.30，爆发不再频繁（约慢 43%）
- **Boss 强化**：血量 +20%（2970/4790/7300）、阶段间隔 1.8/1.5/1.2→1.2/1.0/0.8（射速 +50%）、
  弹速倍率 1.15/1.35/1.55、环形弹 14→18、螺旋弹 3→5、交叉弹补一发中央弹、横向机动 1.2/1.8/1.8

### 自动射击与超载爆发（v2.7.0）
- **全程自动开火**：桌面端不再需要长按 `空格`/`J`，进入关卡即持续射击，只需专心走位（按键仍保留，不影响手感）。
- **道具自动下落**：爆出的 `P`/`B`/护盾/♥ 带初速与加速度下落（45 → 顶速 175 px/s），不再悬停在原地；靠近 130px 仍会被吸附过来。
- **超载能量条（蓝条）**：命中敌机（每点伤害 0.20）、击破（+2.2）、擦弹（+0.30）都会充能，HUD 底部蓝色进度条实时显示。
- **v2.7.0 起改为手动释放**：集满后屏幕底部出现红色【爆发】按钮（或按 `L`），**由玩家决定引爆时机**——清空当前屏幕所有敌机、清掉全部敌弹、奖励 300 分、获得 1 秒无敌；Boss 不会被清屏秒杀，改为承受一次 700 点重创。**一局仅可引爆一次**，引爆后蓝条归零且不再积攒。
  参数集中在 `config.js` 的 `OVERDRIVE`（`PER_DMG` / `PER_KILL` / `BOSS_DAMAGE` / `INVULN` 等）。

### 视听表现
- **程序化绘制**：所有机体、弹幕、粒子、星空、UI 都是代码画出来的。
- **纯 WebAudio 合成音效**：主 / 音效 / 音乐三条独立音量总线。
- **三层视差星空** + 动态星云 + 屏幕震动 + 受击白闪 + 暗角。
- **粒子池 / 子弹池**：循环复用，大规模爆炸也不掉帧。

## 🔧 技术要点

**固定逻辑分辨率 + 容器等比缩放**
游戏内部永远以 `480×720` 逻辑坐标绘制，画布用 `devicePixelRatio` 放大保证高清；外层容器双重约束，横屏、竖屏、小窗口都不会被裁切。

**帧率无关的运动**
所有位移都乘 `dt`，阻尼用指数平滑 `1 - exp(-λ·dt)`；单帧 `dt` 上限 0.1s 防止切标签页回来后物体瞬移。

**对象池**
子弹上限 900、粒子池 1400，用 `swap-pop` 原地删除，避免 `splice` 数组搬移与 GC 抖动。

**独立命中判定**
玩家碰撞半径 9px，视觉翼展约 44px —— 街机手感的关键在于"感觉碰到了才算"。
